#### m3u8二次加密key分析

> `环境`
>
> * win10
> * chrome110
> * 猫爪
> * 视频链接：aHR0cHM6Ly96eXd4Lm5ldC8jL0xlc3NvbnMvMTYx

#### 提取m3u8

打开需要下载的视频，猫爪提取m3u8
![在这里插入图片描述](https://img-blog.csdnimg.cn/8374f0addc7e488f8861ee24905dbdd8.png)
提取到地址后用下载器测试，提示key错误，经过分析是经过了某讯的二次加密
![在这里插入图片描述](https://img-blog.csdnimg.cn/6f44217e321147d1885f558f6c0bee36.png)

#### key分析

查看调用堆栈，点进去随便打个断点分析
![在这里插入图片描述](https://img-blog.csdnimg.cn/535c90bc87b94c7584bfd1402af8b11f.png)
经过断点调试，找到h
![在这里插入图片描述](https://img-blog.csdnimg.cn/f52d8c59c30e45399249bbc6177e6a71.png)
可以很明显看到了key，iv
![在这里插入图片描述](https://img-blog.csdnimg.cn/e8ee3b5a659a46489db254b5796cba38.png)

![在这里插入图片描述](https://img-blog.csdnimg.cn/7c896997f9a545dbb1cf40df8409427e.png)
