#### 3. 破解算法细节

##### 许可证生成流程

1. **构造许可证字符串**：

   ```
   const licenseString = `${customerName}_${licenseType}_${expiryDate}_${version}`;
   ```
2. **计算MD5哈希**：

   ```
   const hash = MD5.md5(licenseString);
   ```
3. **组合完整许可证**：

   ```
   const fullLicense = `${licenseString}_${hash}`;
   ```
4. **Base64编码**：

   ```
   const encodedLicense = btoa(fullLicense);
   ```

##### 关键发现

通过AI分析，发现了几个关键点：

1. **MD5算法**：AG-Grid使用标准的MD5算法，但实现在其自己的代码中
2. **日期格式**：到期日期使用`DD_MM_YYYY`格式
3. **版本号**：通常使用`*`表示适用于所有版本
4. **许可证类型**：包括`SingleApplication`、`MultipleApplications`等

### 技术原理深度解析

#### MD5算法实现细节

AG-Grid使用的MD5算法包含以下关键函数：

```
// 核心MD5循环
function md5cycle(x, k) {
    var a = x[0], b = x[1], c = x[2], d = x[3];

    a = ff(a, b, c, d, k[0], 7, -680876936);
    d = ff(d, a, b, c, k[1], 12, -389564586);
    // ... 更多轮次

    x[0] = add32(a, x[0]);
    x[1] = add32(b, x[1]);
    x[2] = add32(c, x[2]);
    x[3] = add32(d, x[3]);
}
```

#### 许可证验证流程

1. **解码**：将Base64编码的许可证解码为原始字符串
2. **分割**：按下划线分割许可证组件
3. **重新计算**：使用前4个组件重新计算MD5哈希
4. **比较**：将计算结果与许可证中的哈希值比较
5. **日期检查**：验证许可证是否过期
