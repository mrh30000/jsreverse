# 欧易谷歌插件转换成网页

> **作者**: wolfSpicy | **发布时间**: 2025-12-28 12:36:00 | **版块**: 『脱壳破解区』 | **查看/回复**: 3238 / 17
> **原文**: [https://www.52pojie.cn/thread-2082856-1-1.html](https://www.52pojie.cn/thread-2082856-1-1.html)

---

我这几天遇到个奇怪的需求 说是要求把欧易钱包(OKX Wallet)转换成网页方式 方便去自动化操作输入 助记词或短语

因为平时谷歌插件都是popup弹窗方式存在的 所以没办法直接F12 选中对应元素

![](https://attach.52pojie.cn/forum/202512/28/121834ie7wcci9cujzzgdu.jpg)

于是我就去研究了下谷歌的插件应该怎么样才能选中元素然后自动化

后面发现了 其实每个插件本质都是一个网页来的    于是是可以通过url来进行访问

![](https://attach.52pojie.cn/forum/202512/28/122230yl7isbplq3qmgs01.jpg)

**chrome-extension://{extension\_id}/popup.html   这个地址就是欧易的打开界面** **extension\_id  可以在拓展程序中F12 找到**

于是就这样顺利进入了界面

![](https://attach.52pojie.cn/forum/202512/28/122353sgsxs8ytdot700dr.jpg)

当我点击  ->导入钱包  -> 助记词或私钥 的时候结果又变成弹窗了 网页不见了！

![](https://attach.52pojie.cn/forum/202512/28/122825hybhtrwdyw5whyeh.jpg)

那这怎么办  我如果想自动化就必须找到网页元素 但现在没办法找到
于是我想到了调试下看看  给 click事件进行debug

![](https://attach.52pojie.cn/forum/202512/28/123053y8d2divbebvvie55.jpg)

看看有没有可能是经过了js跳转页面    结果一找确实发现了 最后发现经过 this.openwindow后立马出现弹窗

![](https://attach.52pojie.cn/forum/202512/28/123214janralxxaxda3dcw.jpg)

然后一访问 确实是这样的

![](https://attach.52pojie.cn/forum/202512/28/123311uzippvp38mfqqzb0.jpg)

就这样结束了

这次我觉得虽然说很简单
但我了解到了以下几个知识点
1.谷歌插件都是网页形式的 只要是网页就可以访问
2.通过js方式进行弹窗 其实我们可以对插件进行修改的  让它不弹窗  从而也能达到我们的要求
