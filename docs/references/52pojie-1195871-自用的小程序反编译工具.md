**自己用的小程序反编译工具，因为要跳槽了，所以放出来给大家**

**注意:所有的基本执行,vscode已经设置好调试配置,可以直接用vs去执行,这样更加方便**

----------------------------------------------------------------------
主包解压流程
\*\*\*方式一
1.解压wxapkg文件
        node wuWxapkg.js wxapkg文件绝对路径                                         // vscode调试命令  执行wuWxapkg全部流程

\*\*\*方式二,设置好参数后单步执行流程调试
1.只执行wuWxapkg解包
2.执行wuConfig
3.执行wuJs
4.执行wuWxml
5.执行wuWxss

---------------------------------------------------
分包解压

[Asm] *纯文本查看*

```
1.解压wxapkg文件
	node wuWxapkg.js 分包wxapkg文件绝对路径 				// vscode调试命令  只执行wuWxapkg解包
2.还原js文件
	node wuJs.js 分包解压路径下的\app-service.js 			// vscode调试命令  执行wuJs
3.还原wxml文件
	node wuWxml.js 分包解压路径下的\page-frame.js 		// vscode调试命令  执行wuWxml
4.还原wxss文件
	node wuWxss.js 分包解压路径 							// vscode调试命令  执行wuWxss
5.手动把解压出来的分包内容拷贝到主包同一位置
```

另外:
        \* 如果遇到插件项目解析不出来json文件,可以尝试切换wuConfig.js 修改PHM 2

        \* 如果遇到解析不出来js文件情况,尝试切换wuJs.js 修改PHM 3

        \* 如果遇到解析不出来wxml文件情况,尝试切换wuWxml.js 修改PHM 4

        \* 如果遇到解析不出来wxss文件情况,尝试切换wuWxss.js 修改PHM 5
        \* 如果遇到解析不出来wxss文件但是又不报错情况,尝试切换wuWxss.js 修改PHM 6
