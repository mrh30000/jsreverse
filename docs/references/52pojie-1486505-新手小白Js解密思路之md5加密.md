登陆的时候密码被加密了，因为是32位的字母数字随机组合，先猜测过去应该是MD5加密

![](https://attach.52pojie.cn/forum/202108/01/120512n31k3fxbf12880xf.jpg)

搜索“password”来定位加密的位置

![](https://attach.52pojie.cn/forum/202108/01/120607n1hy6yh66psmsohp.png)

看到关键的字母CryptoJS.MD5，找到关键的加密代码，进到里面看下详细的代码

![](https://attach.52pojie.cn/forum/202108/01/120711gwzd78htedh80hhb.png)

结合前后代码分析，这就是md5加密，接下来搜索MD5

![](https://attach.52pojie.cn/forum/202108/01/121127nyh0pxrjdwvrryoz.png)

看它这个JS文件名就是叫md5.js，再进到这个js文件里面看下具体代码，分析后可以看出这个里面的全部代码都是跟MD5有关的，全部复制出来调试一下

![](https://attach.52pojie.cn/forum/202108/01/121148ib8zhbslwnq5qqbz.png)

系统引擎运行，提示错误说明：Microsoft JScript 运行时错误 【'lib' 为 null 或不是对象】

![](https://attach.52pojie.cn/forum/202108/01/121206raiq1tbykpdpjyct.png)

lib对象不存在，为什么会不存在？
Lib是通过C来的，C又是通过CryptoJS来的，CryptoJS是传参进来的，那么我们需要找到CryptoJS这个对象。
再次搜索关键字CryptoJS，找到相关代码

![](https://attach.52pojie.cn/forum/202108/01/121229cr00p6ffuwf13v3e.png)

19行这里有个声明变量CryptoJS的，我们进去看一下详细代码

![](https://attach.52pojie.cn/forum/202108/01/121250p1jgmm61y7ggwgtz.png)

结合代码结尾

![](https://attach.52pojie.cn/forum/202108/01/121309txorxoymdkaly43o.png)

代码的结尾又返回了CryptoJS这个对象，那么这些代码就都是我们需要的，把core.js里面的全部代码全部复制，放到调试工具里面最开头

![](https://attach.52pojie.cn/forum/202108/01/121334tmlc8qi3xrx1vxpq.png)

并且在调试工具的结尾加上调用的代码

function test(password){
        return CryptoJS.MD5(password);
}

参数传入password的参数123456，点击系统引擎运行，返回js加密结果为：e10adc3949ba59abbe56e057f20f883e

![](https://attach.52pojie.cn/forum/202108/01/121410mf2xwse3pms3zexf.png)

对比一下我们在网页提交的密码加密结果是一样的，我们就找到了密码的加密代码。
