### 三、分析加密逻辑

#### 3.1 理解 `pointJson` 的生成逻辑

我们先来看这行关键代码：

```
pointJson = t.secretKey ? o((0, n.default)(t.checkPosArr), t.secretKey) : (0, n.default)(t.checkPosArr)
```

在 JavaScript 中，`?:` 是一个三元运算符，意思是：

* 当 `t.secretKey` 为真值时，`pointJson = o((0, n.default)(t.checkPosArr), t.secretKey)`
* 否则，`pointJson = (0, n.default)(t.checkPosArr)`

我们将鼠标悬停在 `t.secretKey` 上查看其值，可以看到 `t.secretKey = "I6U2jTypdZgh5aCC"`，说明走的是第一个分支：

```
pointJson = o((0, n.default)(t.checkPosArr), t.secretKey)
```

### 四、Python 复现加密

接下来我们用 Python 来实现这个 AES 加密：

```
import base64
from Crypto.Cipher import AES
from Crypto.Util.Padding import pad

def encrypt_data(t, e):
    """
    t: 待加密的明文（文字坐标）
    e: 密钥
    """
    i = e.encode('utf-8')
    s = t.encode('utf-8')
    cipher = AES.new(i, AES.MODE_ECB)
    encrypted_data = cipher.encrypt(pad(s, AES.block_size))
    return str(base64.encodebytes(encrypted_data), encoding='utf8').replace('\n', '')
```
