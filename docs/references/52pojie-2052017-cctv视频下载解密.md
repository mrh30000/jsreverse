最近cctv网页端更新了，加密从以前简单的wasm，现在wasm里面全是vmp了

简单看了下算法应该还是tea，前8字节运算得到key，然后再解密。太复杂搞不定,感兴趣可以自己研究。

之前发过一个客户端解密的（[CCTV WEB和客户端.cbox下载解密](https://www.52pojie.cn/thread-1940562-1-1.html)），看了下还能用，就是以前mac地址传的空，现在不行了，如果有之前用过而且保存了UDRM\_LICENSE.v1.0的现在也还能用。

上面的帖子看不了，简单改了下以前的并加上了mac端的。

使用方法
打开一个网站
1. [https://v.cctv.com/2025/08/08/VI ... 24.Ps6ySUNiMIzG.0.0](https://v.cctv.com/2025/08/08/VIDEfL3wQQiksyUbEbgZ0BRG250808.shtml?spm=C12120290324.Ps6ySUNiMIzG.0.0)
2.按F12（Command + Option + I）打开控制台，然后刷新,搜索m3u8或者hls\_enc2\_url，选择链接

![](https://attach.52pojie.cn/forum/202508/08/194311qrs1wrrizr16azre.png)

3.下载解密

[Bash shell] *纯文本查看*

```
cbox.exe <input url> <output file>  可以直接输入链接或者下载好的的文件(不要转码，只重封装)
```

建议先用N\_m3u8DL-RE或者其他软件下载成mp4在利用软件解密，软件利用的ffmpeg里面的下载功能，速度不一定好。出现下面错误尝试解密本地文件
