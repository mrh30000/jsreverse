正常打开网页，F12,开始寻找媒体文件。

![](https://attach.52pojie.cn/forum/202205/13/235701ztft1bzh5mh8efe9.png)

审查元素
没有找到常规媒体文件（mp4，avi），逐步往下看，发现是m3u8流媒体

![](https://attach.52pojie.cn/forum/202205/13/235723hkznfk40fn2ffffi.png)

拿取连接开始用下载器下载，失败，为m3u8加密，需要key解密才可以正常解析。

![](https://attach.52pojie.cn/forum/202205/13/235751c44z4w0mjuet2942.png)

视频嗅探器也无法直接下载，只能录屏。果断放弃录屏。

![](https://attach.52pojie.cn/forum/202205/13/235812cd3lbs2gtobzjtoe.png)

![](https://static.52pojie.cn/static/image/hrline/1.gif)
正文开始
分析m3u8文件，得知，为某度类，其文件包括了IV，key地址，及key二次加密方式：AES-128

![](https://attach.52pojie.cn/forum/202205/13/235846fc83cstb3oz3dqui.png)

访问key连接，看来不能直接访问

![](https://attach.52pojie.cn/forum/202205/13/235914k0n5t028d5zkk0tn.png)

无效，换一种方式，咱们找找key

![](https://attach.52pojie.cn/forum/202205/13/235954mqkxpmr4qqj8qk9k.png)

得到key

[Shell] *纯文本查看*

```
2e4b4c125bd9b3c7034b8a6f700e6688
```

**于是在下载器中填写key和iv值，但是事情有我们想象的这么简单吗？**

![](https://attach.52pojie.cn/forum/202205/14/000104yte0gpgq49kenou9.png)

key 无效
看来没法下载，开始分析。

* 首先我们知道m3u8的key 应该是一段base64或hex

* 其次如果这么容易就下载了，我的钱不是白花了吗

* 再次，咱们还知道了是aes-128加密，加密解密还没弄呢，怎么就一个key就出来了。

* 最关键的是，如果此“key”是aes128加密的，那么它应该还有一个解密的秘钥，我们需要找到这个秘钥，才能解密此“key”。

那就从播放器下手吧，找到播放器的js，。

![](https://attach.52pojie.cn/forum/202205/14/000428qvccoc5voycizo00.png)

善用搜索找一找key这个关键词
天啊，这么多怎么早，看到眼睛都疼了。但是动动脑筋，有注释，虽然是英文的。

![](https://attach.52pojie.cn/forum/202205/14/000521uh3umpslzguc37zc.png)

但是咱们有翻译啊。change; transform; convert; switch 咱们找找

![](https://attach.52pojie.cn/forum/202205/14/000611att5so4ju00gtftu.png)

最后固定在关键词convert

你很可以的大兄弟

[Lua] *纯文本查看*

```
Handle responses for key data and convert the key data to the correct format（用我大学英语不及格我都能看到） convert the key data to the correct format（转变key成正确的格式）
```

![](https://attach.52pojie.cn/forum/202205/14/000651z1vkz248wtnkn33v.png)

往下找几行，很可疑的一串码出来了。

![](https://attach.52pojie.cn/forum/202205/14/000707dzddpw11y9diwhih.png)

解密的秘钥

[Asm] *纯文本查看*

```
72Fhskjglp8qjpqx
```

试一试吧。

![](https://attach.52pojie.cn/forum/202205/14/000741kyiwzwg21qep2j22.png)

有戏，由于我用的下载器用的是base64格式，做一个转化，得到key

[Asm] *纯文本查看*

```
Um5VWHVEdXZmZ2UzcmY5ag==
```
