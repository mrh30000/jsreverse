H5游戏的修改，替换JS，比较简单吧

#### 需要用到的

1.Chrome

2.插件：偷天换日(结尾有上传)

3.VisualStudioCode(记事本也行能开.JS就行)

4.IIS用来映射文件(不会的百度：开启IIS)

### 正文开始

先进游戏副本，等把要修改的代码加载完，F12->点击Sources->找到要改的JS

![](https://attach.52pojie.cn/forum/202108/10/171121oczor8oeye78cdcg.png)

窍门最大的那几个JS文件,CTRL+F搜个ATTACK//ATK看看有没有多不多，一般符合就是了

![](https://attach.52pojie.cn/forum/202108/10/171123ppddvmclw4e5r885.png)

偷天换日插件打开，作用替换掉原JS，实现修改

![](https://attach.52pojie.cn/forum/202108/10/171125lgc7fnh33qhx77z7.png)

原生填：要替换的JS文件地址（找到原JS右键复制路径复制粘贴过来就行）
代{过}{滤}理：填本地要映射替换的JS文件，直接本地路径JS比较大的话会失效，所以用IIS本地搞个线上映射

![](https://attach.52pojie.cn/forum/202108/10/171127fi2fm2tilfrttnf7.png)

打开IIS先浏览下看看成不成

![](https://attach.52pojie.cn/forum/202108/10/171130l3qjh5zfb5jfjv5v.png)

浏览打开，新建个1.js文件，用VisualStudioCode打开随便写个什么打开看看

![](https://attach.52pojie.cn/forum/202108/10/171132reuvktj422mp7t1m.png)

![](https://attach.52pojie.cn/forum/202108/10/171134cb7pbawxlwpwugzg.png)

![](https://attach.52pojie.cn/forum/202108/10/171136cn6uyr662ow2642f.png)

没毛病继续

![](https://attach.52pojie.cn/forum/202108/10/171140nzjz0g2v7zi03w9u.png)

代{过}{滤}理地址：[http://localhost/1.js写上去就行](http://localhost/1.js%E5%86%99%E4%B8%8A%E5%8E%BB%E5%B0%B1%E8%A1%8C)

![](https://attach.52pojie.cn/forum/202108/10/171143bsejssds67hcw37j.png)

一般都是在原JS基础上修改，直接复制粘贴

![](https://attach.52pojie.cn/forum/202108/10/171147sr5cg50ccgzi1aor.png)

格式化一下代码推荐网站：<http://yajs.quchacha.com/>

复制到1.js上

![](https://attach.52pojie.cn/forum/202108/10/171149y6yknnkjjjn5j6kp.png)

打上勾勾开启 F5刷新看看有没有映射成功

![](https://attach.52pojie.cn/forum/202108/10/171145olhdx1hfytslopxh.png)

看来没毛病，效果图就不放了，懂的都懂，不够一般H5都是页游改了也白改

![](https://attach.52pojie.cn/forum/202108/10/171151muepsmjngg88sn8g.png)
