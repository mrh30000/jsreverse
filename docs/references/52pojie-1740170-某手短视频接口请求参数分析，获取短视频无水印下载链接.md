直接开始了。（下边的免费评分点一点，我想升级了，另外有项目可以直接论坛私信联系我）

第一步：进入某手，随便打开一个人的主页，打开浏览器抓包工具，下拉短视频自动刷新，抓包工具显示接口全局搜索某个短视频名称（也可自己翻翻看看返回的数据，定位到视频接口，短视频名称和链接自己翻翻接口找找就行不要问了，你们可以直接保存链接或者自动下载视频这个我就不管了）

![](https://attach.52pojie.cn/forum/202301/31/080019sk90as7cl90nw0el.png)

![](https://attach.52pojie.cn/forum/202301/31/080119tcnewv637nchn3we.png)

第二步：查看传递载荷，有两个参数需要注意，pcursor(如果你从第一页短视频开始开始抓，发现其为空值，但你在返回值（response）里可以看到它的值，即上一页的请求的返回值携带下一页的请求参数)，userId（看一下主页链接取'/'最后的值即可，看下边的图就明白了），其余的值就直接复制即可。

![](https://attach.52pojie.cn/forum/202301/31/081253nwj90qjqjivrb8ey.png)

![](https://attach.52pojie.cn/forum/202301/31/081159cqouhqlaoxog4osv.png)

![](https://attach.52pojie.cn/forum/202301/31/080259p7mv7aevvvneupov.png)

![](https://attach.52pojie.cn/forum/202301/31/080720ms8x2emxxmiz1m8e.png)

第三步：验证了下请求头和传递的参数，代码在下边了，自己瞧瞧，注意data的传参格式，一开始给你们展示了content-type，是json格式。至于Cookie直接复制自己的就行，请求不要过快（每个请求之间间隔一秒以上就行）反正你带着自己的Cookie请求过快能查到你

![](https://attach.52pojie.cn/forum/202301/31/081758outuvwuzwzcfqfu5.png)

![](https://attach.52pojie.cn/forum/202301/31/081854zjpriz0irp0tuipp.png)

![](https://attach.52pojie.cn/forum/202301/31/082459emkmenkekn7wm4jk.png)

第四步：敲代码，拿到数据。注意cookie的有效期，失效了只能抓到部分，自己再去登录复制一个即可（这么简单的事情我就不回答了，当然也可以弄个自动化浏览器每次设置随机请求头也会返回不同Cookie，就不用自己复制了），某手的请求跟好看视频的逻辑一样，有兴趣自己搞一下，重要的事情讲很多遍，不要请求过快！不要请求过快！不要请求过快！

![](https://attach.52pojie.cn/forum/202301/31/082718t3wjk98089y0m7i9.png)

给大家科普一点：requests中，verify=false 的时候会一直出现一个报错，这时只要添加下面两行代码即可，禁用警告

from urllib3 import disable\_warnings

disable\_warnings()
