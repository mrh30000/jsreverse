新人第一帖，讲讲我在赛尔号启航手游上做的逆向分析
众所周知，赛尔号是个爆肝游戏，很多时候如果用变速齿轮全局变速，对战时候技能要点得很快，这也很不舒服
赛尔号启航整个游戏是由 egret引擎制作，
对战动画使用的是dragonbones js
通过直接改js源码，我们能只控制动画速度，而不缩短出招时间

### 调试JS文件

赛尔号的静态网页里几乎没有什么js代码，主要调用了一个叫bootstrap+（一串时间戳）的js文件，然后使用doucument.append head动态加载这个js
然后这个js再加载其他js，一环套一环
因为这个时间戳不断变化，文件名不一样，上次下的断点再打开就没了，所以把它变成一个固定名字的文件，这就用到*本地替代的功能*

### 浏览器本地替代

原理就是，浏览器会先检查本地是否有要请求的资源，如果有就不会像服务器请求

### 分析多个较大的js文件

发现赛尔号首先会加载几个分别叫
base     bootstrap+'时间戳'
lib     bootstrap+'时间戳'
env     bootstrap+'时间戳'
。。。。
的文件，这几个文件我截取了一些代码进行搜索，发现大部分是egret引擎的库代码，淘米可能做了一些修改
这样的话，我们对照erget的文档，可以直接在这些库文件里的关键函数下断点，比如发送事件的函数。加载2d骨骼动画资源的函数

### 改写发包文件

要问游戏逆向第一要义是什么，我觉得一定是发包
在开发者工具中的网络一栏，选择ws，就能看到赛尔号的ws发包，是没有经过加密的明文（高版本谷歌浏览器能看到）
点击一个ws链接，找发起程序，就能找到一个叫socket{一串数字}的js文件，这个就是发包文件了，
但是这个文件在VM里，没办法本地替代，这就需要往上找这个文件又是从哪个js文件加载来的，然后一直网上找，直到找到一个不是VM的js文件，从这里开始给收到的js内容http包进行修改，在内容最后一行加上//@sourceURL=（随便起个名字），然后再执行原本的document.appendhead 这样这个（随便名字的）js文件就被替代了
PS:（忽然想到，在VMjs里下断点然后改写js内容，不知道能不能直接进行本地替代）
在发包文件里查找字符sendmessage和receivemessage就能找到发包和收包函数

### （真·）简单粗暴法

经过我多天的研究，赛尔号启航有暴漏很多全局变量，在控制台输入

```
MFC.battleManager.pveFight({
    "id": 11,
    "type": 17,
    "catchPet": 0,
    "battleType": 3
})
就能直接开始对战钢牙鲨
GlobalSocket.PROTOCOL_SOCKET.send(1110,{
  "levelId": 80,
  "loop": 10
})
就能直接扫荡10次艾迪星第三层
```
