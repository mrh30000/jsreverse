最后整理一下思路
经过各种拼接出来的明文Json参数{"rid":"R\_SO\_4\_1870390705","threadId":"R\_SO\_4\_1870390705","pageNo":"1","pageSize":"20","cursor":"-1","offset":"0","orderType":"1","csrf\_token":""}
这个参数先经过固定密钥0CoJUm6Qyw8W8jud和偏移0102030405060708经过AES加密得到第一次加密结果
在经过a方法生成随机的密钥和第一次的偏移0102030405060708再次加密得到第二次加密结果
而这个结果就是提交的params参数
