**## 第二步 跟栈找到加密位置**
2.1 我们向上找，可以看到此时我们在目标数据包，并且`X-sign`已经有了，说明加密位置不在这里，然后我们在往上就是异步，如果我们进入异步，断点就不起作用，所以我们要做的是，将条件断点改在异步里面
![](https://attach.52pojie.cn//forum/202505/23/155131ftc48axe32eenn5k.png?l)

2.2 如图所示 `1`的堆栈就是`send`他的前两步所展示的很难读懂，所以在这里不会去解释他，有兴趣的可以去查阅相关资料，我们来看`2` ，在这里他的作用是用于定位，因为`3` 就是我们断点处 他里面的语法是`e.url.includes('param/get\_param\_details')`，而`2`是`e.data`，`e`里面也有不少东西，这样可以去判断我们的目标数据包经过这里没有，从而去做下一步操作或更换堆栈，`这是我个人理解如果有更好的关于条件断点解释，可以留言给我`
![](https://attach.52pojie.cn//forum/202505/23/173830gkq4rvnqqgvo741l.png?l)
2.3 在2.2 我们也没有见`x-sign`的生成并且`e`里面的`headers`已经有了`x-sign`所以我们，接着向上跟栈，直到看不见`x-sign`或者`"x-sign":a(或者其他变量)`这样形式
![](https://attach.52pojie.cn//forum/202505/23/173336qkwnyajx0zi58atj.png?l)
2.4我们将断点移步到`i.apiGetData`这个堆栈，条件断点还是`e.url`，我们来查看`e`里面的东西，我们看到`x-sign`没有了，我们就可以猜测是不是在`clientAxios.axiosHttp()`方法里面生成的`e,n`是要传入的参数，但这样看范围太大了我们单步调试进入看一下，里面有没有关于`x-sign`的地方

**## 第三步 寻找加密最终位置**
3.1我们在2.4看到了`headers`里面已经没有`x-sign`了，所以我们就可以猜测这个`clientAxios.axiosHttp()`方法，里面存储了加密，进入看一下
![](https://attach.52pojie.cn//forum/202505/23/174017om9wuize1uw6pemb.png?l)
![](https://attach.52pojie.cn//forum/202505/23/174019ffgfk699ulu0ffzu.png?l)
3.2 进入之后往下看在红箭头处有点可疑，因为我们在2.3说过，他可能是`"x-sign":a...`等等种形式，那么在这里他有个`headers: clientAxios.getHeaders(e, t)`跟我们说的有点相似都是对象形式，那么有没有一种可能,这个函数返回一个对象其中包括`x-sign`，为了验证我们就进入看一下
![](https://attach.52pojie.cn//forum/202505/23/174050mgaim6j532vy6zaj.png?l)
3.3 我们滑动到尾部,发现他尾部的流程是在往`r`里面添加,并且我们顺着红箭头去看，他也有`x-sign`,那我们就知道了，`3.2`讲述的内容符合我们的猜测，`r["x-sign"] = s(e, t)`就是我们需要的加密

**## 第四步 分析`x-sign`加密函数**
4.1 既然要分析我们就要去查看这`s`方法里面的流程，将断点直接放在这里进入，然后我们来解析这个方法流程和所用到的参数
![](https://attach.52pojie.cn//forum/202505/23/174126vg4g46gc5ykkpo1c.png?l)
4.1我们看到进入这个函数之后，并且我们单步调试，发现他走的是`if`没有进入`else`那么我们就可以更快的去分解：

- 下面这两段是所用到的参数是函数头部`function s(e, t)`；
  `var i = e.data ?JSON.stringify(e.data) : "{}", o = r(e, t);`
   `n = "cid=" + t.cid +   "&#182;m=" + i + o + t.timestamp；`
   最后将`if`里面的`n`传给尾部 `var s =   yicheUtils.md5(n);`

- 所以我们只需要查清楚函数头部形参`e,t`里面的内容就可以完成上面的代码的改写 其中` o = r(e,   t)`这个方法主要用的是形参t出了时间戳其余是固定的

4.2我们再来分析`var s = yicheUtils.md5(n);`，经过多次日调试他就是标准的`md5`加密所以加密可以调用标准库和自己扣取
