### 扣代码

![](https://attach.52pojie.cn/forum/202510/12/214411ndkc99k2c81wb1xe.png)

扣下，然后 d is not defined

![](https://attach.52pojie.cn/forum/202510/12/214508zgo5b9cn4z43zcl9.png)

看到一个大数组要警觉，很大概率后面会有一个自执行函数（IIFE）对这个大数组做重排处理，大数组 + 自执行重排，是常见的混淆手段

d 连带着自执行一并扣下，然后 g is not defined

![](https://attach.52pojie.cn/forum/202510/12/214601cbe51feege3jyjyy.png)

扣下，然后 l is not defined，而 l 于开头定义

![](https://attach.52pojie.cn/forum/202510/12/214627fk4is66ez0b4kss3.png)

n("xxxx") 形式，那必是 webpack 了，刷新网页断住，跟进 n

![](https://attach.52pojie.cn/forum/202510/12/214658b0z9vhq3scil0utx.png)

文件内是一整个自执行，全扣下

在加载器 l 里插个桩并导出为 myLoader，并把整个 webpack 内初始化的执行注释掉

```
function l(t) {
    console.log(t); // 插桩，打印加载的模块
    if (a[t])
        return a[t].exports;
    var n = a[t] = {
        i: t,
        l: !1,
        exports: {}
    };
    return e[t].call(n.exports, n, n.exports, l),
    n.l = !0,
    n.exports
}
```

![](https://attach.52pojie.cn/forum/202510/12/214808u4fy1zfya9kx32ck.png)

执行，桩日志加载 8237，Cannot read properties of undefined (reading 'call')，说明缺了，全局搜，补上

![](https://attach.52pojie.cn/forum/202510/12/214848w00n9ozoq29xrrge.png)

此文件头语句为 `(window["webpackJsonp"] = window["webpackJsonp"] || []).push([["chunk-vendors"], {...}])`，与主 webpack 的绑定语句 `var s = window["webpackJsonp"] = window["webpackJsonp"] || []` 相对应

因为不知道还会加载哪些模块，直接全扣
