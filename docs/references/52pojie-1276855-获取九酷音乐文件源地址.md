# 获取九酷音乐文件源地址

**系统：Windows10专业版64**
**工具：Chrome developer tools、postman**
**语言要求：JavaScript**

**第一步：打开调试工具，随便播放一首音乐**
>如果是第一次播放，会请求一次音乐文件，之后都是读取的缓存。

![](https://attach.52pojie.cn/forum/202009/30/000051edaq0gn7v0edvv0v.jpg)

**第二步：复制音乐文件地址，添加到断点。刷新页面看是否能捕获到该请求。刷新之后并没有捕获到，那么接下来换一种方式试试**

![](https://attach.52pojie.cn/forum/202009/30/000434vcpejjj1pjpfpmq4.jpg)

**第三步：查看播放按钮的点击事件。在图3中，可以看到有好几个点击事件。为了确定哪一个点击事件是有效的播放事件，这里可以保留一个点击事件，其他的都移除（点击Remove）。**

![](https://attach.52pojie.cn/forum/202009/30/000646aos1c3zoomq31y8y.jpg)

**第四步：经过筛选，获取到有效的播放事件**

![](https://attach.52pojie.cn/forum/202009/30/001324lmuap2roxroks0p0.jpg)

**第五步：点击该点击事件（图4红色框内蓝色字部分），随后会进入到一个JS文件，我们点击箭头指示的按钮，格式化这个文件。**

![](https://attach.52pojie.cn/forum/202009/30/001358emumg1z5m5wwu15x.jpg)

**第六步：格式化之后，会进入到第1436行。这里下一个断点（断点位置会在1437行）**

![](https://attach.52pojie.cn/forum/202009/30/001629q662w63jo123qxt4.jpg)

**第七步：刷新页面，然后点击播放按钮。如果不出意外，会进入到断点处。简单看下调用了什么函数，变量中有哪些信息。有没有特别的地方（主要寻找音乐文件的地址）**

![](https://attach.52pojie.cn/forum/202009/30/001829b55gaq9z1oqjxo1j.jpg)

**第八步：单步调试，按F9或找一找图7红色框内第一行中的按钮。如果不知道这几个按钮是干什么的，那就随便点呗，反正点不坏！**
**图八是第一次单步之后的界面，这里也没有我想要的数据**

![](https://attach.52pojie.cn/forum/202009/30/001831xvl8lrblroir5inb.jpg)

**第九步：继续单步执行（大概走6、7步），直到图9这个地方。这里可以看到this.status中有了音乐文件的播放地址（this.status.src）；**

![](https://attach.52pojie.cn/forum/202009/30/003659pwf9j33yqhhfqu5b.jpg)

**第十步：搜索this.status.media或this.status.src赋值的地方，我只找到了this.status.media赋值的地方（图十中1265行）。**
**当然，这只是其中一种方式，还有其他方式也可以获取到这个播放地址，这里就只展示这一种。**
**在这里下个断点，然后刷新页面**

![](https://attach.52pojie.cn/forum/202009/30/001835du8maqq85o8jt2a9.jpg)

**第十一步：查看调用的函数，其实根据函数名这里已经可以找到获取播放地址的地方了。**
**但有点偷懒的意思**

![](https://attach.52pojie.cn/forum/202009/30/001838u37qsq651wwg3ywt.jpg)

第十二步：从setMeida函数依次点击它下面的函数（先调用的函数在下面），直到图12这里，发现了media这个变量就是音乐文件地址

![](https://attach.52pojie.cn/forum/202009/30/001844pq99dxzy3y1h4jef.jpg)

**第十三步：继续看下面的函数，图13中可以看到yesplay函数中对media进行了赋值**

![](https://attach.52pojie.cn/forum/202009/30/001846uz9fs3mkklz5skif.jpg)

**第14步：在图13中520行下个断点，刷新页面。看看dict.get是干嘛用的。图14中可以到，它只是this变量中的一个值**

![](https://attach.52pojie.cn/forum/202009/30/001849asj6qtjb86tui9pm.jpg)

**第15步：继续看下面的函数，直到getmusicinfo这个函数，这个函数中的item变量包含了音乐文件地址**

![](https://attach.52pojie.cn/forum/202009/30/001851x1jn4o3rnhr14toj.jpg)

**第16步：仔细看一下这个函数，如果在item变量没有值情况下，会请求一个JS文件。并把相应的数据储存到缓存中。**
**请求路径中的两个变量：id和tpath，id可以从当前播放路径获取，tpath不多说。**

![](https://attach.52pojie.cn/forum/202009/30/001853u9obbxgqfhi5udi5.jpg)

**第17步：postman测试API，结果：可以获取到。**

![](https://attach.52pojie.cn/forum/202009/30/010459p93g3a93z3y6ckgg.jpg)
