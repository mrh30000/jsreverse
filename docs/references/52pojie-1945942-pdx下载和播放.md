v12 的 可以直接合并成mp4 ,需要设置 -custom-hls-method Polyv 和  --seed-const

[Asm] *纯文本查看*

```
N_m3u8DL-RE.exe "https://hls.videocc.net/9215d65496/b/9215d654961c54e786c5eb33cecf4e3b_1.pdx" --tmp-dir ./cache --save-dir ./Download --save-name "1697442267278116" --custom-hls-method Polyv --custom-hls-key 98d2ea568b5316a9eb9aae8596ef2241 --seed-const 215 -H "Referer:[url]https://www.yiihuu.cc[/url]"
```
