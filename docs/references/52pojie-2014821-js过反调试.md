​`setTimeout`​ 是一个函数，用于在指定的毫秒数延迟之后执行提供的函数或代码片段一次。

例子：

```
function greet() {
  console.log("2秒后显示你好！");
}

// 在延迟 2000 毫秒（2 秒）后调用 greet 函数
setTimeout(greet, 2000);

console.log("这条消息会立即显示。");
```

往上面跟栈，可以发现`setInterval`​定时器会每隔2000毫秒来执行

> ​`setInterval`​是JavaScript中的一个内置函数，它允许你以指定的时间间隔重复执行一个函数或一段代码。简单来说，它会创建一个定时器，每隔一段时间就自动调用你提供的函数，直到你显式地停止它，或者浏览器窗口关闭。
>
> ​**​`setTimeout`​**​**和**​**​`setInterval`​**​**主要区别：**
>
> * **执行次数：**
>
>   + ​`setTimeout`​：只执行一次。当指定的延迟时间到达后，它会执行一次指定的函数或代码。
>   + ​`setInterval`​：重复执行。它会按照指定的时间间隔，反复执行指定的函数或代码，直到被显式停止（使用 `clearInterval`​）或窗口关闭。
> * **执行频率：**
>
>   + ​`setTimeout`​：延迟指定时间后执行一次。
>   + ​`setInterval`​：每隔指定时间间隔重复执行。

往栈底走，这里就是检测代码，打上断点，刷新网页，然后在控制台注入hook代码

我们可以通过hook技术来让他如果调用参数的是`debugger`​就返回一个空函数

```
      (function() {}
        ["constructor"]("debugger")())
----相当于
new Function("debugger")();
```

hook代码

```
(function() {
    const originalFunctionConstructor = Function.prototype.constructor;

    Function.prototype.constructor = function(...args) {
        if (args.length > 0 && args[0] === 'debugger') {
            // 拦截到了 "debugger" 构造，可以进行一些操作
            console.log('拦截到 debugger 构造：', args);
            // 可以选择阻止原始构造函数的调用，或者修改其行为
            // 例如，返回一个空函数
            return function() {};
        }
        // 如果不是 "debugger" 构造，则调用原始构造函数
        return originalFunctionConstructor.apply(this, args);
    };

    // 恢复原始构造函数，避免影响其他代码
    // Function.prototype.constructor = originalFunctionConstructor;
})();
```
