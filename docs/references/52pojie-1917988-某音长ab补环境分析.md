## 流程分析

我们先观察下这个ab的大体详细啊

![image-20240426110942563](https://imgsrc.baidu.com/forum/pic/item/aa18972bd40735fa0c34c985d8510fb30e2408c2.jpg)

发现恒定长是168啊（但具体还是看个人电脑，我朋友有的是172长度，不过问题都不大）。

直接断点进栈。

![image-20240426111141520](https://imgsrc.baidu.com/forum/pic/item/7a899e510fb30f24acab6a3f8e95d143ad4b03dd.jpg)

然后再这个地方打上条件断点  然后f5刷新网页

```
s.apply(b, u).length==168
```

![image-20240426111228557](https://imgsrc.baidu.com/forum/pic/item/5882b2b7d0a20cf449a278e330094b36acaf99d8.jpg)

进栈。看看ab能否正常输出。顺便记住这个两个关键的数值  1582，6

![image-20240426111604410](https://imgsrc.baidu.com/forum/pic/item/cb8065380cd79123e6cd1248eb345982b2b780d9.jpg)

接下来复制整个vmp代码 到浏览器片段中。

现在难点就是我们如何去寻找bdms怎么初始化加载并调用的函数生成ab的

可以确定的是这个索引是 \_v的第3个

![image-20240426112500425](https://imgsrc.baidu.com/forum/pic/item/58ee3d6d55fbb2fb7e07de2e094a20a44623dcda.jpg)

我们上文提到两个值 1582，6 现在我们用这两个去当作索引寻找调用函数，

一个一个去找。 找\_v 与 \_u  只调用一次的地方。

（如果这里嫌麻烦可以全部点开然后搜搜1582就可以快速定位，虽然繁琐，但总比算法还原简单的多）

索引位置如下

```
window.bdms.init._v[2].p[42]
```

![image-20240426112823754](https://imgsrc.baidu.com/forum/pic/item/aa64034f78f0f73651d2ca3d4c55b319ebc413da.jpg)
