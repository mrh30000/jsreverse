## 原理分析

打开Reqable选择调试某学网，完成一次并不出色的单词PK，发现列表中出现了一个特别的POST请求`https://wordsbtl-api.up366.cn/client/wordsbtl/student/submit`

这不用测试都能看出来是干啥的。

看了Body格式为Urlencoded，接下来就是分析里面内容了。

```
submitJson
totalNum
score
wrongLength
```

好嘛，这含义小学英语就能看懂了。

直接获取totalNum，score设置为totalNum，wrongLength设置为0。

那么如何处理submitJson就是个问题了。

我们使用JSON库解析submitJson，发现所有不优雅的地方answerStatus都是0，那我们把answerStatus设置为1就行了。

其它的标头都不方便伪造，所以就不改了。

```
from reqable import *
import urllib.parse
import json

def onRequest(context, request):
    if request.method == 'POST' and request.mime == 'application/x-www-form-urlencoded':
        # 解析为键值对列表
        parsed = urllib.parse.parse_qsl(request.body.payload, keep_blank_values=True)

        # 转换到字典以便查找
        data_dict = {}
        for key, value in parsed:
            if key == 'submitJson':
                try:
                    json_data = json.loads(value)
                    total_num = json_data.get('totalNum', 0)

                    # 修改totalNum、rightNum和score
                    json_data['totalNum'] = total_num
                    json_data['rightNum'] = total_num
                    json_data['score'] = total_num

                    # 修改所有answerStatus为0的项
                    if 'wordInfos' in json_data:
                        for word_info in json_data['wordInfos']:
                            if word_info.get('answerStatus') == 0:
                                word_info['answerStatus'] = 1

                    data_dict[key] = json.dumps(json_data, ensure_ascii=False)
                except:
                    data_dict[key] = value
            else:
                data_dict[key] = value

        # 设置wrongLength为0
        data_dict['wrongLength'] = '0'
        data_dict['score'] = total_num
        # 重新编码
        new_body = urllib.parse.urlencode(data_dict)
        request.body.text(new_body)

    return request
def onResponse(context, response):
  # Update status code
  # response.code = 404

  # APIs are same as `onRequest`

  # Done
  return response
```

## 解决方案

1. 配置Reqable Windows环境，确保证书已经被安装，代理端口(默认为9000)能够正常访问
2. 启用脚本工具，导入配置好的脚本(为了长久白嫖cf的cdn，配置好的脚本仅在我的博客可见，52pj论坛友可以看附件)(未经许可，禁止转载)
3. (可选)修改脚本中的目标单词分数，确保您不会被老师打死
4. 打开某学网，选择【设置】>【代理】，选择`HTTP代理`，主机填写`127.0.0.1`，端口填写`9000`
5. 开始你的单词PK吧!
