## 攻击链分析

### 初始入口（Initial Entry）

一个批处理文件（`Lark.bat`）使用 PowerShell 从以下地址下载并执行远程脚本：

`http://187.127.255.206/kkkk-xxxx-eeee-hhhh-bububu.txt`

该脚本会隐藏 PowerShell 窗口（`ShowWindow(0)`）。

### 第二阶段下载器（Second-Stage Downloader）

隐藏窗口运行的 PowerShell 脚本从同一 IP 下载 `script.php`（实际上是 PowerShell 代码）。

该脚本内包含一个经过 AES-256-CBC 加密的载荷（Payload）。

### 第三阶段载荷（Third-Stage Payload）

经过另一层 AES 解密后，最终获得真正的恶意 PowerShell 脚本。

## 最终恶意脚本的行为

### 静默下载

从以下地址下载恶意可执行文件：

`https://hosting.iptusp.com/installer_mts_1905.exe`

### 计划任务执行

创建隐藏的计划任务，在当前登录用户权限下静默运行下载的 EXE：

* 使用 Inno Setup 静默安装参数：`/VERYSILENT`
* 文件被解压至：`C:\Users\Public\SVN\versions\<随机数字>\`

### 信息窃取

收集以下信息：

* 计算机名称
* 用户名
* 系统区域设置（Locale）
* 当前时间

随后通过 HTTP POST 发送到：

`https://hosting.iptusp.com/contar.php?id=mts`

### 单次执行标记

写入标记文件：

`%LocalAppData%\MachineCounter\executed.txt`

用于避免重复感染同一台设备。

### 自我清理

删除：

* 下载的 EXE 文件
* 创建的计划任务

从而只保留已安装的恶意程序。

## 风险等级与影响

### 高风险

攻击者可能：

* 完全控制被感染主机
* 执行任意代码
* 窃取敏感数据
* 植入持久化后门

### 强隐蔽性

采用：

* 静默安装
* 隐藏窗口
* 自动删除计划任务

因此用户通常不会察觉感染。

### 信息泄露

设备信息被上传至远程服务器，可能用于后续定向攻击。

### 规避检测技术

攻击链采用：

* 多层 AES 加密
* 动态下载
* 使用公共目录 `C:\Users\Public`
* 伪装成合法安装程序行为

## 应急响应措施

### 立即断开网络连接

防止：

* 数据继续泄露
* 横向传播

### 删除以下内容

目录：`C:\Users\Public\SVN` 及其所有子目录。

计划任务：名称包含 `InstallTask_` 的任务。

文件：`%LocalAppData%\MachineCounter\executed.txt`

### 检查异常进程

重点关注从 `C:\Users\Public` 启动的程序。

### 进行完整杀毒扫描

建议使用可信杀毒软件，并优先选择离线扫描（Offline Scan）。

### 修改所有密码

由于计算机名称和用户名已经泄露，建议更换所有账户密码。

### 在网络层面封锁

* IP：`187.127.255.206`
* 域名：`hosting.iptusp.com`

> 如果无法确保系统被彻底清理，建议直接重装操作系统。

## 总结

这是一个典型的**多阶段、加密且高度混淆的恶意软件下载器（Downloader）**。

最终投放的 `installer_mts_1905.exe` 具有极高危险性。

整个攻击链展示了现代恶意软件如何利用：

* 批处理文件（Batch）
* PowerShell
* AES 加密

绕过传统安全防护机制。

强烈建议安全运维人员将该 IP 与域名加入黑名单，并对内部主机进行全面排查。

普通用户应避免运行来自不可信来源的：

* `.bat` 批处理文件
* `.ps1` PowerShell 脚本文件
