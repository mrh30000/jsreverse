* 前言

            今天探索水晶DJ音乐网。本人小白一个，希望大佬看到不要嘲笑。

* 准备工作

1、你需要有一个浏览器(这句话有点多余...)
2、JS调试工具
3、基础的编程

* 第一步

首先，注册送15个水晶，所以我先找个便宜的音乐来做参考。

[HTML] *纯文本查看*

```
参考网址：[url=http://www.dj97.cn/m/129921/]http://www.dj97.cn/m/129921/[/url]
```

然后F12调出控制台。进入→Network→F5刷新

![](https://attach.52pojie.cn/forum/202107/03/163554wzkkkykyvyxam5mx.png)

然后我们发现一个(或多个 网址一样)MP4格式的网址 转到新页面播放没画面，只有音乐。

[HTML] *纯文本查看*

```
http://m.oscaches.com/mp4/djmusic/newDj/20210701/梁咏琪-Today(梧州DJ欧东Mix2021Electro)完整.mp4
```

![](https://attach.52pojie.cn/forum/202107/03/163757gil62oh2a06izkii.png)

下载下来，发现音频是95kbps，显然不符合我们的要求，我们接着下载这首歌，抓一下下载的包。

![](https://attach.52pojie.cn/forum/202107/03/163934qoiukxkdyi0ikdiq.png)

购买下载后，我们把鼠标指向随便一个下载链接。发现会跳转到音频链接。这个链接就是320kbps音质。

[HTML] *纯文本查看*

```
http://a19c2ac6.oscaches.com/mp3/newDj/20210701/梁咏琪-Today(梧州DJ欧东Mix2021Electro)完整.mp3
```

然后我们分析一下结构，网址结构为：

http://a19c2ac6.oscaches.com/mp3/newDj/20210701/梁咏琪-Today(梧州DJ欧东Mix2021Electro)完整.mp3

http://a19c2ac6.oscaches.com/mp3/newDj/时间/音乐文件名.mp3

然后我们去源代码找一下文件名和时间

[HTML] *纯文本查看*

```
if (navigator.userAgent.match(/iPad|iPhone|iPod|Android/i) != null) location.href = location.href.replace('www.dj97.cn', 'm.dj97.cn');
var curr = {id: 129921, type: '7', name: '梁咏琪 - Today(梧州DJ欧东Mix2021Electro)完整', file: 'newDj/20210701/梁咏琪-Today(梧州DJ欧东Mix2021Electro)完整', good: 1, click: 11.00, next: 129921, pre: 129920};
```

![](https://attach.52pojie.cn/forum/202107/03/164350nj5vjthswei6tqsi.png)

直接找到时间和文件名。我们再随便找个付费的音乐套进去试试。

[HTML] *纯文本查看*

```
参考地址：[url=http://www.dj97.cn/m/129913/]http://www.dj97.cn/m/129913/[/url]
```

我们查看源代码，把时间和文件名套进去

[HTML] *纯文本查看*

```
参考地址：[url=http://a19c2ac6.oscaches.com/mp3/newDj/20210701/DJFany-]http://a19c2ac6.oscaches.com/mp3/newDj/20210701/DJFany-[/url]靓仔建专属定做经典粤语(他朝心中不想你)保时捷911扣女狂飙摇摆节奏慢摇串烧.mp3
```

然后打开链接，发现可以播放，然后我们下载下来看看音质。

![](https://attach.52pojie.cn/forum/202107/03/164820g98b6ihtihj4j518.png)

下载后发现，确实是320kbps。到此，教程结束

**注**：本教程仅用于2021和2020年发布音乐 以前音乐另加了两个目录。正在找方法
