[JavaScript] *纯文本查看*

```
function md5Encrypt(input) {
    // 确保输入是字符串
    const str = typeof input === 'string' ? input : String(input);
    return crypto.createHash('md5').update(str, 'utf8').digest('hex');
}

console.log(md5Encrypt(123456));   // 同样输出 e10adc3949ba59abbe56e057f20f883e
```
