我的一个小网站，我不访问可能一个流量都没有。今天打开后，突然劫持跳转到另一个 xxx 垃圾站。

因调试一个程序，开了fiddler，所有的访问都被记录了下来。
网站情况：宝塔7.90，PHP7.0
网站没有被入侵，服务器也安全（至少目前没检查到）。

访问网站后，/js/jquery-3.5.1.min.js 被换成了一个加了一些代码的 js 文件。但是我服务器的js 文件又是正常没有替换的。

![](https://attach.52pojie.cn/forum/202212/04/222616yl6yo6op76rqnj66.png)

打开控制台后会暂停。
看到  document[\_0x2551[9]](unescape(\_0x2551[8])); 直接找到

[Asm] *纯文本查看*


在控制台输入，显示了真凶！

解析出来此内容大概是 调用了 hxxps://www.metamarket.quest/market.js  这个js文件。但是服务器内容正常。
多次（无缓存）刷新我的 /js/jquery-3.5.1.min.js 后，/js/jquery-3.5.1.min.js  内容回复正常。
