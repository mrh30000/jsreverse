function hash(input) {

## 对比hash加密函数 （var p = function(N) ）

发现是DeepSeek输出的加密逻辑与网页不一致, 修正如下：

单个字符并非是加密3次，而是加密20次

```
function hash(input) {
    let hashValue = 0;

    for (let i = 0; i < input.length; i++) {
        const charCode = input.charCodeAt(i);

         for (let y = 0; y < 20; y++)
            switch (y % 3) {
                case 0:
                    hashValue = B(hashValue, charCode, y);
                    break;
                case 1:
                    hashValue = J(hashValue, charCode, y);
                    break;
                case 2:
                    hashValue = Y(hashValue, charCode);
            }
    }

    return hashValue;
}
```
