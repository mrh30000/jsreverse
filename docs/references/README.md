### 通道是怎么发现的

`hubcli 52pojie Thread --help` 明写支持「**四种类型帖子列表（精华、热门、技术、最新，或指定版块 URL）**」：

```

hubcli 52pojie Thread --url https://www.52pojie.cn/forum-24-3.html --page 3   # 指定版块第 3 页
```

历轮只把它当「一个最新列表」整体处理，**从未按 `type` 分档核对，也从未用过 `--url` 版块枚举**。
两条新通道的实测结论完全不同：

| 新通道 | 规模 | 池外比例 | 结论 |
| --- | --- | --- | --- |
| **四类策展榜**（digest 176 / hot 67 / tech 334 / newthread 381） | 958 唯一（第 9 页空） | **仅 6 篇池外** | 已被历轮池覆盖；**web 逆向内容 0**（精华/技术榜清一色 native·Android·CTF·病毒；热门榜是软件分享） |
| **版块枚举**（7 个白名单版块 × 30 页） | **8881 唯一** | **7668 篇池外（86%）** | ✅ 真正的增量来源 |

版块枚举的池外比例：原创发布区 **86%** / 编程语言区 **55%** / 脱壳破解区 **42%** ——
说明历轮「关键词搜索 + 策展榜」构成的 17770 全量池**远未覆盖全站**：
关键词是**标题短语匹配**，标题里不含那 586 个词形的老帖永远进不了池。

### 一处口径修正（坑 51）

`build_probe20d.py` 首版用 `\bsign\b|\bjs\b|\bapi\b` 这类**带词边界**的正则，
结果「某图君 sign 破解」「jQuery Hook」这类中英混排标题**全部漏掉** ——
Python `re` 的 `\b` 以 `\w` 为界，而**中文属 `\w`**，`君` 与 `s` 之间没有边界。
（与第五轮 `\bast\b` 对「某数 ast+jsdom」失效是同一个坑。）⇒ 中英混排场景**一律不加 `\b`**。
