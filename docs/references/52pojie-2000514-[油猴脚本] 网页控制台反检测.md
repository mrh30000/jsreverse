## 0x00 背景

逆向过程中，经常有网站一打开控制台，就弹出无限debugger，有的网站，右键“永不在此处暂停”后点击继续执行，还会直接跳转到别的网站页面，不让调试；再配合一些代码混淆，对于我们小白来说，有的时候想开始逆向都很难下手。

本工具就是为解决这个问题而写的。

## 0x02 安装

这是一个[用户脚本](https://zh.wikipedia.org/wiki/%E7%94%A8%E6%88%B6%E6%8C%87%E4%BB%A4%E7%A2%BC)，因此你首先需要明白[怎么安装用户脚本](https://greasyfork.org/zh-CN/help/installing-user-scripts)。

需要注意的是，本脚本利用了Tampermonkey的 *Content Script API: Userscript API Dynamic* 功能，因此使用Tampermonkey脚本管理器是最佳选择。使用其他脚本管理器也可以，但是Tampermonkey对本脚本的兼容性、运行稳定性、使用便利性都会更好。

**安装链接：<https://greasyfork.org/zh-CN/scripts/523792>**

## 0x03 用法

注意这个脚本 **不是** 装上就能直接开始用的，它需要hook页面上的一些函数，这将难免对页面的兼容性造成一些影响。因此，在设计上并不会一开始就自动在每个页面都运行，**你需要手动将想要调试的页面添加到脚本的作用域里来**。这里以Tampermonkey为例：

1. 安装好脚本后，在Tampermonkey已安装脚本列表找到此脚本，打开脚本的编辑页面，然后点击脚本的 *设置* ，如图：![](https://p.sda1.dev/21/c6635499230b07e29d6cdbe7b0cab431/image.png)
2. 进入脚本的设置，找到 *包括/排除* ，把想要调试的页面添加到 *用户包括* 中：![](https://p.sda1.dev/21/0071e2cbd0e4373a185abab5dd7c7d45/image.png)
   这里的格式大致和通配符语法一致，具体可以参考[Tampermonkey文档对此的说明](https://www.tampermonkey.net/documentation.php#meta:match)

如果你使用的正是Tampermonkey，还可以进行一项额外的配置，以让脚本可以最快速地注入到页面中运行，提升稳定性和兼容性：

1. 首先打开Tampermonkey设置，将 *配置模式* 设置为 *高级*，如图：![](https://p.sda1.dev/21/3fc57479306c90778205414e39da700e/image.png)
2. 还是在设置界面，找到 *安全* - *Content Script API*，设置为 *Userscript API Dynamic*，如图：![](https://p.sda1.dev/21/cd88f91802e63fc815b1c88e4713c11e/image.png)
3. 最后不要忘了点击 *保存*：![](https://p.sda1.dev/21/509ccdc41e56f547dc003f33517efb1a/image.png)

## 0x04 FAQ / 常见问题解答

#### 0x04.1 为什么还是会出现无限debugger？

我们已经努力将以下形式的debugger过滤去除：

* `function() {}.constructor('debugger')()`
* `Function('debugger')()`
* `new Function('debugger')()`

但用户脚本不是万能的，并不能直接修改网页运行的代码，因此那些直接写死在网页js中的debugger语句仍然会执行。你可以通过 ***右键行号-永不在此处暂停*** 解决。

#### 0x04.2 为什么要调整Tampermonkey的设置？

因为我们的脚本需要尽早运行，最好能早于页面上的一切其他代码，这样才方便我们拦截页面上对浏览器控制台的检测；而Tampermonkey的 *Content Script API: Userscript API Dynamic* 选项正好可以帮我们实现这一点。

#### 0x04.3 为什么不直接在所有页面运行，一定要手动添加需要调试的页面？

因为我们的脚本需要Hook（修改）页面的部分API，难免对网页兼容性造成影响。

#### 0x04.4 按照步骤安装配置好脚本以后，打开控制台还是被检测到了。。

* 有可能是脚本执行时间不够早，导致拦截失败。可以在 *网页控制台-网络* 选项卡中 *禁用缓存* - *模拟网速为3G/慢速4G* - *刷新页面* 试试，让网页加载慢一点，我们的脚本运行就相对提前了
* 如果还是不行，有可能是网页用了一些未知的检测方法，没有被拦截到，欢迎 [反馈](https://greasyfork.org/zh-CN/scripts/523792/feedback)

#### 0x04.5 是否支持手机浏览器/第三方控制台/等等？

这个脚本是给PC端浏览器、原生控制台设计的，手机浏览器、第三方控制台等请自行测试是否有效，原则上我不作支持。

#### 0x04.6 开启脚本后，控制台里有好多垃圾输出

一些检测控制台是否开启的检测器会不断输出垃圾数据到控制台，为此脚本提供了一个禁止网页向控制台输出消息的功能，可以通过Tampermonkey的菜单按钮按需开启。
