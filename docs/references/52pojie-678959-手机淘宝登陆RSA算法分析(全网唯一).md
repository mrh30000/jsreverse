# 手机淘宝登陆RSA算法分析(全网唯一)

首先给大家介绍一下手机淘宝吧.(本文纯静态分析)
他这边是用一种插件化的开发方式去写的,至于什么是插件化http://blog.csdn.net/yulong0809/article/details/59113935
当然这篇文章不是主要去讲什么是插件化.
回归主题,我们来看看淘宝的APK结构

![](https://attach.52pojie.cn/forum/201712/23/161539zjwju8mwmy11fziu.png)

用分析工具搜索login关键字在mainfest

![](https://attach.52pojie.cn/forum/201712/23/162042c3hx8nsl30sn70ih.png)

看到com.taobao.login4android   这个是登陆模块的包名
你们也可以自己看淘宝的包名是com.taobao.taobao
那我们就开始寻找login4android

![](https://attach.52pojie.cn/forum/201712/23/162524qj11dx7azeoxr1u1.png)

在lib中找到了这个模块,然后我们可以解压这个SO 文件(这个SO文件不是native的,是一个APK可以直接解压出来)

![](https://attach.52pojie.cn/forum/201712/23/162846mtr2ppwtwpkhwwpw.png)

从资源文件中可以不难看出来这个就是我们需要找的登陆模块

![](https://attach.52pojie.cn/forum/201712/23/164437widbwllssswljjd5.png)

登陆的模块的在这里线索就断了
LFk,jRm,rFk  这3个都不是这个APK里面的类,bFk是一个BroadcastReceiver.

现在换个角度去分析,从UI布局这里入手

![](https://attach.52pojie.cn/forum/201712/23/165044xwppbpa0vauupp0p.png)

![](https://attach.52pojie.cn/forum/201712/23/165044d6tzgcmgo63a267g.png)

当然淘宝的登陆有很多类,我只是拿其中的一种来分析
我们又看到新的突破口
taobaouser\_login\_fragment
然后我们搜索这个fragment在哪里调用的就好

![](https://attach.52pojie.cn/forum/201712/23/172919s110kkb59rshqqlb.png)

这个你可以往父级元素里面去看  是一个fragment
我们找到了这个layout对应的fragment

![](https://attach.52pojie.cn/forum/201712/23/173312uhq4wqq00lpbb0sz.png)

![](https://attach.52pojie.cn/forum/201712/23/173313p62t9m58w8fvwo53.png)

查找这个fragment的点击事件,有忘记密码,帮助,但是没有登陆的事件,所以说登陆的事件不在这里进行处理
然后我们查看JT这个类的父类 dt这个类

我们找到了登陆的点击事件了
loginInCurrentEnv();  这个方法处理异步请求

![](https://attach.52pojie.cn/forum/201712/23/174412zgcxtoz2ettj26je.png)

看到这里大家知道他把所有的参数都放到一个实体类进行了保存起来

![](https://attach.52pojie.cn/forum/201712/23/174623gwuuw9woiqzu9ovz.png)

然后调用了AS的login方法,
us里面是个AsyncTask  他又调用了AS的unifyLogin方法(这个就不上图了,有点小麻烦)

![](https://attach.52pojie.cn/forum/201712/23/175029n2mzxz1llio10p12.png)

这里IS这个类里面 大家可以看看,登陆的参数都写在这里面,算法也是,因为是纯静态分析,所以我也不知道有没有TOKEN,他有2种登陆方法

![](https://attach.52pojie.cn/forum/201712/23/175349oe1hedwffhenaade.png)

这边我们分析的是第二种方式,这个很明显获取一个RSA的公钥,然后去加密.

![](https://attach.52pojie.cn/forum/201712/23/175527ijl3giwhxbjz2xcj.png)

最后RSA的算法在哪里,快过年了,发一份福利给大家吧,祝大家新年快乐吧.
