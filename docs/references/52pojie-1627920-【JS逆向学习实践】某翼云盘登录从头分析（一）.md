又找来一个练手站点，地址就不放了，有兴趣的可以自己去找，首先抓包分析

![](https://attach.52pojie.cn/forum/202204/26/110037adnhnkhn3fc4lcc3.png)

可以看到出现图片验证码，请求中有一项needCapture的请求，这是判断是否需要验证码其返回值为1则为需要，为0则不需要，看下请求数据

![](https://attach.52pojie.cn/forum/202204/26/110223v8dxnlaci8azjmae.png)

一共三项数据，只有userName是动态变化的，明显看到是经过加密的，先解密吧，从入口跟进去

![](https://attach.52pojie.cn/forum/202204/26/110354kul4d99ik0090u12.png)

跟进去之后可以看到，请求地址一样，将userName进行了RSA加密

![](https://attach.52pojie.cn/forum/202204/26/110506wfjmjlg4aajfz0gj.png)

Rsa可以抠代码也可以套用现成的库，我这里抠加密代码，下断点

![](https://attach.52pojie.cn/forum/202204/26/110758mezokiv2kev3eph3.png)

跟进去看到实际上调用了encrypt的encrypt的方法进行加密，看下encrypt是JSEncrypt，将他抠出来

![](https://attach.52pojie.cn/forum/202204/26/111201jo2izi4vt4v2ilcc.png)

是一个导出函数，跟进去将他们全部抠出来就行了

![](https://attach.52pojie.cn/forum/202204/26/121008tecee0rcep5ykerr.png)

将全部代码复制出来，折叠方便看，可以看到下面有一个var JSEncrypt = JSEncryptExports.JSEncrypt，这个JSEncrypt就是上面的那个对象了，再看一下加密函数

![](https://attach.52pojie.cn/forum/202204/26/121325pookojcsjjwjwtcj.png)

它是由RSA\_Pwd这个对象调用的，看下这个对象，里面有一个setPublicKey

![](https://attach.52pojie.cn/forum/202204/26/121433faffjsbfysynj9rc.png)

分析可以看到，这个Key是动态请求的，我们为了方便测试直接写固定的，下面是调用代码

