## h1仅适用于蜻蜓FM未改版电台播放地址算法

其实就是拼接了一下地址 hmac\_md5 算法 密码：Lwrpu$K5oP

```
t ＝ “/live/” ＋ id ＋ “/64k.mp3”
n ＝ “https://lhttp.qtfm.cn”
i ＝ “web”
r ＝ 取十六进制文本 (Unix时间戳 (增减时间 (取现行时间 (), #小时, 1)))

a ＝ “app_id=” ＋ i ＋ “&path=” ＋ t＋ “&ts=” ＋ r

sign ＝ hex_hmac_md5 (“Lwrpu$K5oP”, a)

返回 (n ＋ t ＋ “?app_id=” ＋ i ＋ “&ts=” ＋ r ＋ “&sign=” ＋ sign)
```
