#### 🦊3.3分析滑块图片，先读其灰度图将其裁剪，然后与背景图片对比，获取从背景最左边到缺口最左边的相对距离

```
def identify_gap(bg_path, tp_path):
    # 读取背景图片并转为灰度图
    bg_img = cv2.imread(bg_path, cv2.IMREAD_GRAYSCALE)
    # 读取缺口模板图片并转为灰度图
    tp_img = cv2.imread(tp_path, cv2.IMREAD_GRAYSCALE)

    # 初始化两个列表，用于存储模板图中像素值小于200的像素的横纵坐标
    yy = []
    xx = []

    # 遍历模板图的每个像素点（再次读取tp图用于获取尺寸）
    for y in range(cv2.imread(tp_path).shape[0]):
        for x in range(cv2.imread(tp_path).shape[1]):
            # 获取当前像素的灰度值
            r = tp_img[y, x]
            # 如果像素值小于200，认为是有效的图像区域
            if r < 200:
                yy.append(y)  # 记录纵坐标
                xx.append(x)  # 记录横坐标

    # 根据收集到的有效像素点的范围，裁剪出模板图中包含缺口的最小矩形区域
    tp_img = tp_img[min(yy):max(yy), min(xx):max(xx)]

    # 对背景图和裁剪后的模板图进行Canny边缘检测
    bg_edge = cv2.Canny(bg_img, 100, 200)
    tp_edge = cv2.Canny(tp_img, 100, 200)

    # 将边缘图像从单通道灰度图转为3通道RGB图（用于模板匹配）
    bg_pic = cv2.cvtColor(bg_edge, cv2.COLOR_GRAY2RGB)
    tp_pic = cv2.cvtColor(tp_edge, cv2.COLOR_GRAY2RGB)

    # 在背景图中匹配模板图，使用相关系数归一化匹配方法
    res = cv2.matchTemplate(bg_pic, tp_pic, cv2.TM_CCOEFF_NORMED)
    # 获取匹配结果中的最大值及其对应的位置
    min_val, max_val, min_loc, max_loc = cv2.minMaxLoc(res)

    # 获取模板图的高度和宽度
    th, tw = tp_pic.shape[:2]
    # 匹配到的左上角坐标
    tl = (max_loc[0] - 6, max_loc[1])
    # 右下角坐标 = 左上角 + 模板宽高
    br = (tl[0] + tw + 6, tl[1] + th)
    # 在背景图上用红色矩形框出匹配到的区域
    cv2.rectangle(bg_img, tl, br, (0, 0, 0), 1)
    cv2.line(bg_img, (0, 10), (tl[0], 10), (0, 255, 0), 5, 4)
    # 将画有矩形框的背景图保存为 distinguish.jpg
    cv2.imwrite('distinguish.jpg', bg_img)

    # 输出并返回缺口的横坐标
    return tl[0]
```

这样当我们运行时传入两张图片就可以实现距离的计算，如下：


#### 🎃3.4使用计算的距离计算滑动的步骤

作者才艺不精，让他走一步停一下，然后再走再停，循环慢慢接近缺口

```
def path_plan(n, distance):
    i = 0
    while True:
        if distance > n:
            distance = distance - n
            i += 1
        else:
            break

    path_list = []
    for i in range(0, i, 1):
        path_list.append(n)
    path_list.append(distance)

    print(path_list)

    return path_list
```

当我们调用它：

```
x_list = path_plan(40, x)
```

返回一个列表，比如x=97：

```
x_list = [40, 40, 7]
```

### 我们只需要按照他的每一个元素，走一下停一下
