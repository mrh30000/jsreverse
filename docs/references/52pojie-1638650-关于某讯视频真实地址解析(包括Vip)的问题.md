近期在使用油猴进行追剧时，突发奇想，能否自己解析出vip视频的真实地址，查阅了相关资料，在前人的基础上对一些代码做出了修改，适应最新的版本。一、获取vid

[Java] *纯文本查看*

```
public static String getVid(String url) {
		String vid = "";
		try {
			String vidContent = Jsoup.connect(url).get().toString();
			Pattern pattern = Pattern.compile("\"V\":\".*\"");
			Matcher matcher = pattern.matcher(vidContent);
			if (matcher.find()) {
				String first = matcher.group().replaceAll("\"V\":\"", "");
				vid = first.substring(0, first.indexOf("\""));
			}

		} catch (IOException e) {
			e.printStackTrace();
		}
		return vid;
	}
```

以上代码的逻辑为:访问视频所在的url地址，获取到界面的dom元素，使用正则表达式，获取到dom中vid，一个视频可能有多个vid即一个vid的list列表，本例中取单个vid做示范(一个视频有多个vid的情况为：总视频被切割成一个个的小视频)

```
public static List<Video> parse(String url){
		List<Video> urls = new ArrayList<>();//存放最后得到的视频真实地址
		String vid = getVid(url);
		String definition = "fhd";
		Map<String, String> data = new HashMap<>();
		data.put("isHLS", "False");
		data.put("charge", "0");
		data.put("vid", vid);
		data.put("defn", definition);
		data.put("defnpayver", "1");
		data.put("otype", "application/json");
		data.put("platform", "10201");
		data.put("sdtfrom", "v1080");
		data.put("host", "v.qq.com");
		data.put("fhdswitch", "0");
		data.put("show1080p", "1");
		String content = null;
		try {
			content = Jsoup.connect("http://h5vv.video.qq.com/getinfo").data(data).post().toString();
			System.out.println(content);
		} catch (IOException e) {
			e.printStackTrace();
		}
		reader = new SAXReader();
		try {
			Document document = reader.read(new ByteArrayInputStream(content.getBytes("UTF-8")));
			String a=document.getStringValue();
			Element root = document.getRootElement();
			List<Element> uis = root.element("vl").element("vi").element("ul").elements("ui");
			List<Element> fns = root.element("vl").element("vi").elements("fn");
			String realFileName=fns.get(0).getTextTrim();
			String url_prefix = uis.get(uis.size()-1).element("url").getTextTrim();
			Element fvKeyE=root.element("vl").element("vi").element("fvkey");
			String fvKey=fvKeyE.getTextTrim();
			String streamId = null;
			String filename = null;

			List<Element> fis = root.element("fl").elements("fi");
			for (Element fi : fis) {
				if (!fi.element("name").getText().trim().equals(definition)) {
					continue;
				}
				streamId = fi.element("id").getText().trim();
//				List<Element> cis = root.element("vl").element("vi").element("cl").elements("ci");
				List<Element> cis = root.element("vl").element("vi").elements("cl");
				for (Element ci : cis) {
					String keyId = ci.element("keyid").getText().trim();
					data.put("format", streamId);
					data.put("filename", realFileName);
					data.put("vt", "217");

					String keyUrl = "http://h5vv.video.qq.com/getkey";
					try {

						String keyContent = Jsoup.connect(keyUrl).data(data).post().toString();
						Document keyDocument = reader.read(new ByteArrayInputStream(keyContent.getBytes("UTF-8")));
						Element rootElement = keyDocument.getRootElement();
						String key = rootElement.element("key").getText().trim();
						realFileName=rootElement.element("filename").getText().trim();
						String realurl = url_prefix+realFileName+"?&vkey="+key;
						Video video = new Video();
						video.setUrl(realurl);
						urls.add(video);

					} catch (IOException e) {
						e.printStackTrace();
					}
				}
			}
		} catch (DocumentException e) {
			e.printStackTrace();
		} catch (UnsupportedEncodingException e1) {
			e1.printStackTrace();
		}
		return urls;
	}
```

参数详解：
1、isHLS ：false   未知（待讨论）
2、charge：0 未知（待讨论）
3、 vid ：上述函数中获取的vid
4、defn ：清晰度（清晰度 sd普通  hd高清  shd超清 fhd1080）
5、defnpayver ：1 （貌似是什么版本）
6、otype ：application/json 返回值的类型
7、platform ： 10201 （平台？）
8、sdtfrom ： v1080 (可能是清晰度相关)
9、host ：v.qq.com 源地址相关
10、fhdswitch ： 0  （什么开关的状态）
11、show1080p ： 1（是否显示1080p的开关）
