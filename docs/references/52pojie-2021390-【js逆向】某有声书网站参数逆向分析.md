## 三、分析解密函数

![](https://attach.52pojie.cn/forum/202504/03/183632y6inyc7mys6y66y4.jpg)

根据上面的代码逻辑，得到主要实现如下：

```
import urllib.parse
def decode_base64(input_str):
    base64_chars = 'abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789+/='
    decoded = []
    temp_buffer = 0
    buffer_length = 0

    for char in input_str:
        if char == '=':
            break
        index = base64_chars.find(char)
        if index == -1:
            continue

        temp_buffer = (temp_buffer << 6) | index
        buffer_length += 6

        if buffer_length >= 8:
            buffer_length -= 8
            decoded.append((temp_buffer >> buffer_length) & 0xFF)
            temp_buffer &= (1 << buffer_length) - 1

    hex_str = ''.join(f'%{byte:02x}' for byte in decoded)
    return urllib.parse.unquote(hex_str)

def rc4_encrypt_decrypt(input_str, key):
    # 初始化S盒
    S = list(range(256))
    j = 0

    # KSA密钥调度
    for i in range(256):
        j = (j + S[i] + ord(key[i % len(key)])) % 256
        S[i], S[j] = S[j], S[i]

    # PRGA伪随机生成
    i = j = 0
    result = []
    for char in input_str:
        i = (i + 1) % 256
        j = (j + S[i]) % 256
        S[i], S[j] = S[j], S[i]
        t = (S[i] + S[j]) % 256
        keystream = S[t]
        result.append(ord(char) ^ keystream)

    return bytes(result).decode('latin-1')
```

对sp下断点，继续分析。
跟入`_0x59aa87["izZIM"]`
先有一堆变量初始化，不用管它。

![](https://attach.52pojie.cn/forum/202504/03/183637womzsjqyoi7qyiek.jpg)

下面的那个for循环才是重点。

经过分析，发现其定义了一个字符集。

![](https://attach.52pojie.cn/forum/202504/03/183638jmdqlqb7ppbpmg8c.jpg)

可以看到这里有一个控制流混淆(平坦流)，用来生成sp参数。

> 平坦流通常指的是一种将嵌套或复杂的数据结构“扁平化”为简单的、线性的数据流或事件流

![](https://attach.52pojie.cn/forum/202504/03/183638a4kzofv4ommrovwg.jpg)

正确的执行顺序：case3->2->0->1->4

简单解释一下：
**1.**先查找sc中的字符在字符集中的索引。
**2.**然后判断其是否存在。
存在->则将索引加3,再将结果取模 62(确保索引在字符集范围内)；
不存在->直接以当前循环的次数为索引。
**3.**再随机生成两个随机索引。
**4.**最后通过索引将这三个字符进行拼接并加入sp中。

也就是说，sp中每3个字符只有中间的那个是有用的，旁边的两个完全随机。

最后经过简化，得出代码如下：

```
charset = "PXhw7U1B0a9kQDKZsTjIASmOeNzxYG4CHo1JyRfg2b8FLpEvr3FtVnlqMidu6c"
sc_str = ""
result = ''

for char in sc_str:
    idx = charset.find(char)
    processed_char = char if idx == -1 else charset[(idx + 3) % 62]

    # 原case流程：3->2->0->1->4
    rand1 = int(random.random() * 62)
    rand2 = int(random.random() * 62)

    result += charset[rand1] + processed_char + charset[rand2]
```
