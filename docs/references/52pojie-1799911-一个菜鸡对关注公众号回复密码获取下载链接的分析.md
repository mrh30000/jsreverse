这个**b64DecodeUnicode**有点眼熟啊..

```
function b64DecodeUnicode(a) {
    return decodeURIComponent(atob(a).split("").map(function(b) {
        return "%" + ("00" + b.charCodeAt(0).toString(16)).slice(-2)
    }).join(""))
}
```

base64解码再把双引号转为url编码？？？

想到那个令我眼熟的参数。。回去看看。。
