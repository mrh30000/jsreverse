**声明: 分析链接地址仅仅是****方便****个人用播放器看直播(网页太卡)**
**若有人将其用于其他商业用途,造成的后果自负,与本人无关**
需要准备环境：
Nodejs （CryptoJS库）
python3 （bs4，requests）

随便进入一个直播间 F12打开调试界面，刷新观察请求。
发现有个 https://xxxxx/lapi/live/getH5Play/<room\_id>的请求返回了直播地址。

![](https://attach.52pojie.cn/forum/201908/03/185855f6infptww6le47m9.jpg)

这个请求有 v,did,tt,sign 等这些参数，那么这些参数如何生成了，现在就要跟踪这个请求发起过程， chrome devtool真是神器，鼠标放在请求右边的js文件上，就可以看到请求的调用栈，

![](https://attach.52pojie.cn/forum/201908/03/185858ygda3m2m2mpc29as.jpg)

最上面playerSDK js是只负责发送请求的，不做参数处理， h5\_video .. js才是关键。 这地方就需要耐心，需要按顺序点开函数看是否有关键信息。
点开第二个时就发现了信息，在vi函数中看到调用了 window.ub98484234 这个函数，后面cdn rate ver 是不是有点熟悉， 就是前面那个直播源请求的参数，
大胆猜想一下 后面的代码大概就是拿拼接好的参数执行ajax

![](https://attach.52pojie.cn/forum/201908/03/185901ohozk87786j76z8k.jpg)

找到了 ub98484234 这个函数的调用，那么就去看看这个函数怎么实现的，
突然忘了一点，还要看看这个函数需要什么参数 这时候需要在该行代码上打断点（单击左边 4000行号 变蓝色即可） F5刷新页面，稍等片刻就会执行到这里

![](https://attach.52pojie.cn/forum/201908/03/190212swopz5au0aqayaoj.png)

经过对比，ub98484234 需要的参数分别是： 房间号，did， 时间戳 可以在console里实验一下，算出的sign和第一次是相同的

![](https://attach.52pojie.cn/forum/201908/03/190702gutvi0mjicqnaigg.png)

现在，就来看看ub98484234函数怎么实现 在console 直接输入ub98484234（因为它是window上的方法）回车，就看到了代码，点击可以看到代码具体位置。

![](https://attach.52pojie.cn/forum/201908/03/190803zoe169w093rr0wmn.png)

其实就在主页html里，看到代码吓一跳，一行代码，经过了混淆，完全看不懂 管它的，我们能运行就好 这里需要一个js运行环境，就用nodejs吧
将script里的代码全复制出来 写入一个js文件中 在末尾加上一句调用 ub98484234( 0,"32543654",346524754); 这里只是判断能运行 参数随便 然后用node运行，咦 报错了 用到了 MD5 依赖 CryptoJS ，

![](https://attach.52pojie.cn/forum/201908/03/190829pz8ro8kgzqqp6eyg.png)

需要安装 CryptoJS 库，也很简单 命令行里直接运行 npm install crypto-js 就好了 并在js文件第一行加上 var CryptoJS = require("crypto-js"); 把最后调用改成 console.log(ub98484234(2279072, "da0f7bbee4b77225057ece0e36281501", 1564821573)) 在次执行

![](https://attach.52pojie.cn/forum/201908/03/190845ne4v2xf41eete4yw.png)

耶，好了哎 到这个地方，教程其实已经完了。

用node执行js获取参数 构造请求获取数据就ok了，

用potplayer播放偶尔掉线 参考另一个帖子的方法改成 https://tx2play1.douyucdn.cn/(20360rZpP3ffGq9X).xs?uuid= 括号里的自行替换

观察发现，每个主播的算法都不一样，但是一个主播的算法是固定的， 所以获取一个主播的js后可以复用

一大坨js看着实在难受，最近发现是先拼好代码 用eval执行，就给魔改了，可以输出简洁的js代码，相关文件见附件
