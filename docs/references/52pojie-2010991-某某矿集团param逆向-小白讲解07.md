![](https://attach.52pojie.cn/forum/202503/03/132057h4zzlth5gl7764d5.png)

               我们需要按照 3.1 从新操 作 然后一直单步执行下去 直到下图

7.2 同样也是在加密位置的上面 可以看到 先进行 f = t(“8237”)  然后是 B = t.n(f) 我们扣取下来,
       紧接着我们看到打印出了，这个模块没有，所以我们按照 6.1 到 6.2 步骤 进行扣取模块并放入加载器

7.3 我们完成对B()的某块补全 并且通过 接着报错 t.encryptLong 不是方法 这是为啥，
          我们就可以回到浏览器，查看浏览器，的t.encryptLong 是什么东西 ，因为他是t里面出来的，
                而且我们模块并没有在报错就表明我们模块里没有缺失什么，所以我们就要回到浏览器看这个 t.encryptLong
                     为什么在t里 导致我们的没有这个方法的原因是什么，我们回到浏览器查看

![](https://attach.52pojie.cn/forum/202503/03/135911efz1em2ruht828th.png)

7.4 我们看到他不是直接在模块里的而是 在此处赋值的  d["a"].prototype.encryptLong  在他原型下，
        那么我们就要分析了，是在什么时候赋值给他的，可以先看  d["a"]  他是在模块使用之后 给他原型下赋值的，
         而不是 new 之后 在赋值 ，因为new是获得一个实例不能再进行原型下的操作。所以要在他new之前 进行原型赋值，
       然后再new（这是我的理解，有不对的还请大佬们纠正），所以我们就要在他new之前将这段代码添加进去

![](https://attach.52pojie.cn/forum/202503/03/140054rvm5kvjmzdmmm51v.png)

![](https://attach.52pojie.cn/forum/202503/03/140129yy98gqcb3zf43q8l.png)
