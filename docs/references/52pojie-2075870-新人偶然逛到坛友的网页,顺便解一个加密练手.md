# 新人偶然逛到坛友的网页,顺便解一个加密练手

偶然在论坛看到一个药品说明书查询网站,

![](https://attach.52pojie.cn/forum/202511/26/184534xihigrtgr66ivvf1.png)

进入后顺便按了下F12看接口,结果看到了一串加密的data,瞬间来了一点兴趣,尝试解一下~~

![](https://attach.52pojie.cn/forum/202511/26/184536y5m5mm4m54iprrom.png)

直接搜索这个接口的关键词试验一下,看看能不能找到

![](https://attach.52pojie.cn/forum/202511/26/184538o2w2or1zh2pch1rj.png)

找到一处,点进去看看

![](https://attach.52pojie.cn/forum/202511/26/184540vx5ebx585t5etxx5.png)

![](https://attach.52pojie.cn/forum/202511/26/184542pz6qzleea4eape1f.png)

接口返回的data是加密的 重点看data在JS里面是怎么解密的
看到这个代码
let f = JSON.parse(r2(a.data.data));

直接理解成:
json解析(r2函数(接口返回的data))

然后直接设置一个断点验证一下

![](https://attach.52pojie.cn/forum/202511/26/184544lis0udk8px2n800v.png)

设置好断点后,刷新下网页

![](https://attach.52pojie.cn/forum/202511/26/184547b0j80lvzovwda6ao.png)

回到DevTools窗口,看看断下来的内容

![](https://attach.52pojie.cn/forum/202511/26/184549fv0vynzn1vz41ddv.png)

![](https://attach.52pojie.cn/forum/202511/26/184551sghomgozfrb3gdh9.png)

这里可以看到data是接口里面的加密字符串,f是解密后的字符串,那么就可以确认这个r2就是关键的解密函数了

直接在这个页面搜索r2 看看有没有结果

![](https://attach.52pojie.cn/forum/202511/26/184553mvku0zi1h2anhana.png)

从代码可以看出来是aes-cbc解密,找个在线AES解密的网站验证一下

![](https://attach.52pojie.cn/forum/202511/26/184555lu5110h7bzz61hx8.png)

解出来的数据无误,完成一次简单的分析.
