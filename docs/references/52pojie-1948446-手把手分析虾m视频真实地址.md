### 实战开始

1. 浏览器打开开发者模式，输入网站请求

   ![](https://attach.52pojie.cn/forum/202407/27/012158rpnenyfzbenyjxjn.png)

   直接就请求完成了，没有复杂的无限debugger；省了很多事情；
2. 观察ur请求
   上面的请求不多，都点点看看，注意请求的参数与响应体

   ![](https://attach.52pojie.cn/forum/202407/27/012205uh0iubh0hl0hdiho.png)

   细心的同学会发现，这个xmflv.js的请求很诡异，居然是个post请求，响应体是个图片，图片还是裂图，这里边绝逼有鬼，看看这个请求结果到底是什么。
3. 分析怀疑的请求
   这个请求提供两种方式

   * 将图片下载本地，然后以文本打开该文件

     ![](https://attach.52pojie.cn/forum/202407/27/012203s5ynn42tzvojaq4z.png)

     ![](https://attach.52pojie.cn/forum/202407/27/012200ez4vj4aaguj5fpum.png)
   * 复杂请求的url，在控制台查看请求响应结果

     ![](https://attach.52pojie.cn/forum/202407/27/010438vzsov3z1odnkfdks.png)

     ![](https://attach.52pojie.cn/forum/202407/27/010436tx3yt6o4tcn4yckt.png)

     可以发现，加密结果和加密方式 key iv都出现了，解密看看结果，正是最终的直链地址(这里就不贴图了)
4. 分析算法

   ![](https://attach.52pojie.cn/forum/202407/27/010433wk911u99j45p9xm1.png)

   现在目标很明确了，就是获取上述接口的4个请求参数
   wap：是固定的 1
   url：是需要解析的官网地址url
   time：一眼就看出是时间戳
   就剩下 key 参数了，接下来要进行断点跟踪了，这里提供两种方式

   * 关键字搜索
     尝试 key:   "key":  'key':进行全局搜索，最终发现 'key': 能跟到目标代码处

     ![](https://attach.52pojie.cn/forum/202407/27/021505o9hn9zp0zok5p6e4.png)
   * XHR接口断点
     我们知道请求的url，可以添加url断点,再重新请求

     ![](https://attach.52pojie.cn/forum/202407/27/010431kgmzrx2xyopxl4rv.png)

     ![](https://attach.52pojie.cn/forum/202407/27/010429i1uii1ahiahhz1ww.png)

     点击请求的上游调用栈，很快就找到了请求参数生成地方

     ![](https://attach.52pojie.cn/forum/202407/27/010427o4zdzuq4ko8p0840.png)

     key 的生成算法是：

     ```
     sign(ll1lIl1l['KKVzz'](hex_md5, ll1lIl1l[IliIiIi(0x7c7, 'Sx)X')](I111ill, url)))
     ```

     算法混淆比较简单，我们在console打印每一步参数与function

     ![](https://attach.52pojie.cn/forum/202407/27/024852a1dd1ddc3dzdgsad.png)

     转换下 key = sign(hex\_md5(time + url))
     在追踪sign跟 hex\_md5方法

     ![](https://attach.52pojie.cn/forum/202407/27/010423m3vvyvh3yi5qy9mv.png)

     sign是标准AES CBC加密

     ![](https://attach.52pojie.cn/forum/202407/27/010421aiitbdho62uy9i6d.png)

     好复杂，根据方法名，盲猜是MD5后再hash，随便找个参数验证一下

     ![](https://attach.52pojie.cn/forum/202407/27/010418km7dod1kkq85kdlu.png)

     晕， 直接就是MD5呀，分析结束。
5. 全局关键字搜索
   通常在上面第2步分析url没有头绪时，可以直接全局搜索关键字，最常用关键字：decrypt

   ![](https://attach.52pojie.cn/forum/202407/27/021300gwfc3cz33b7fcib1.png)

   再跟踪调用栈，也找到目标解密代码处

   ![](https://attach.52pojie.cn/forum/202407/27/021258mszhh3h1tl03oixx.png)
