### AES加密结果的BASE64编码

在调试的过程中发现AES加密的结果并不是简单的BASE64编码，如下图:

![](https://attach.52pojie.cn/forum/202004/22/165732ozpbe1e5ypcp7p11.jpg)

![](https://attach.52pojie.cn/forum/202004/22/165826va9apv339c1pbehi.jpg)

![](https://attach.52pojie.cn/forum/202004/22/170325wwtvvv1v2nvw1wct.jpg)

```
/**

function create_key() {

```
