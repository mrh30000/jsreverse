**正文**
       首先找到了游戏的jsc文件，例如我们这里就是GlobalDefine.jsc，如何找到？我手机是ios平台的，直接越狱，然后在程序文件里面就能找到这个。然后，安装项目，也就是https://github.com/irelance/jsc-decompile-mozjs-34（大致就是安装一个php环境，然后用composer导入项目所需）注意这里是SpiderMonkey 34 ，一定要分清楚，应用不同的版本型号字节码解析也不同！！！ jsc文件说白了就是字节码文件，这个项目的作用就是将字节码还原成源码（当然不是逐一还原），理论上可以还原。
       安装好项目后，我们用dos命令切换到项目地址也就是有run.php的那个地址，然后我们输入

[C#] *纯文本查看*

```
php run.php GlobalDefine.jsc > test.txt
```

     输出文件test.txt就是还原后的代码，这里截取一小部分感受一下

     整体的逻辑还是可以看出来的，当然了，我们要修改游戏的代码，还是需要做一下功课。
游戏的修改
      首先我们用010 Editor 打开GlobalDefine.jsc 文件 查找  d7 64（为什么查找这个代码稍后会做解释）

![](https://attach.52pojie.cn/forum/201810/30/143611o2rm53hsgrh2uqr2.png)

我们把附近的十六进制代码贴出来解释下

[Asm] *纯文本查看*

```
3B 00 00 00 11      D7 64     12      44 00 00 00 2A    51
```

3B 00 00 00 11
这个代码的大致意思就是查找下标为11的变量 然后把它压入堆栈 这里 下标为11所指的就是的就是GAME\_INFO\_CHANNEL这个变量。
D7 64
将一个八位整数 100 推入堆栈 （就是类似于 int i= 100 ，然后如果不是8位int类型的话就用58 10 10  （这是16位）   还可以用 d8 00 00 00 11（这里是32位））
12
判断前面两个数值是否相等  ，也就是GAME\_INFO\_CHANNEL 和 100 （拓展  相等 -> 12    大于等于 -> 17   大于 -> 16  小于等于 -> 15    小于 -> 14  不等于 -> 13）
44 00 00 00 2A
将堆栈值的顶部转换为布尔值，如果结果为true，则跳转到当前字节码的32位偏移量
51
从堆栈中弹出最高值

这里呢，3B 00 00 00 11 D7 64 12 44 00 00 00 2A 51 对应的代码就是GAME\_INFO\_CHANNEL == 100 这个代码。
然后依次类推到后面的代码  就可以知道
3B 00 00 00 11 D7 65 12 44 00 00 00 2A 51  —>  GAME\_INFO\_CHANNEL == 101
3B 00 00 00 11 D7 66 12 44 00 00 00 2A 51  —> GAME\_INFO\_CHANNEL == 102
...

推出这些有什么用呢？我们可以逐一对应到代码然后就可以修改下面的一些代码值了。

我们往下推，也就推到
6E 00 00 00 CA 43 6F 00 00 00 00 C6 98 这里就不做解释了直接代表的是IS\_CLOUD\_ARCHIVE = true（ (0x42) false    (0x43) true 这里查看字节码的解释可以知道就是设置布尔值 var flag= true；）

6E 00 00 00 CA 43 6F 00 00 00 00 C6 98 ->

[C#] *纯文本查看*

```
//是否使用http加密
IS_USE_HTTP_ENCRYPT = true;
```

这里我们把 第六位的43改成42 就可以使 IS\_USE\_HTTP\_ENCRYPT = true  变为IS\_USE\_HTTP\_ENCRYPT = false 通俗点将就是不再使用http加密明文传输。

其他的变量也就是这样修改 包括一些基本数值，和一些布尔变量，最重要的是找到特定的代码，不行的话就从开始往后推。
